# Design Requirements — Mandatory AI Design Gate

This repository is subject to the Sibling6ix mandatory design-quality gate.

Before any feature, page, interface, user-facing workflow, or visual product is considered complete, evaluate and fulfill all four design requirements:

1. **Taste** — apply strong visual taste and intentional design judgment; avoid generic AI-generated UI, weak hierarchy, arbitrary spacing, poor typography, and visual inconsistency.
2. **Impeccable** — perform a systematic UI/UX refinement pass covering hierarchy, spacing, typography, responsiveness, accessibility, interaction quality, and polish.
3. **Awesome Design.md** — use the project's Awesome Design.md principles/reference standards as a design-quality checklist where available; if the source is external, preserve the applicable principles in the implementation process.
4. **ImageToThreeJS** — evaluate whether image-driven or 3D/Three.js treatment can materially improve the experience. If not applicable to this project/feature, explicitly record the decision rather than silently skipping the requirement.

## Completion Rule
A project or feature is **not design-complete** until these four gates have been evaluated and the applicable improvements implemented. Non-visual/backend work must document why a visual gate is not applicable rather than ignoring it.

This document is a mandatory instruction for AI coding agents and human contributors working on this repository.
